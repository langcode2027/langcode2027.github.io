Starter notebooks

Two Colab notebooks with TigerCoder-1B on a free T4 GPU: one prompts the model, the other fine-tunes it on the trial set. Each scores the trial set step by step and writes a dev submission.zip for CodaBench. They install the six toolchains and download the data and scorer themselves.

Each problem is a function signature in one programming language (Python, C, Lua and others) with a problem description in one of 50 natural languages. Every problem has about 50 test cases. The trial file shows 5 of them and the scorer holds them all; the dev and test files show 2. The natural language of a problem is not given. There is no official training set: you may use any public data, models and tools. Each line of a file is one problem with task_id, entry (the function name), prompt, tests and, in the trial set only, canonical_solution. Tune your system and practice submitting on CodaBench with the dev set; make your final solutions on the test set.

One problem, many languages

The task builds on mHumanEval ↗ (NAACL 2025), a multilingual extension of HumanEval. Each problem is described in one of 50 natural languages, grouped into the classes of Joshi et al. (2020) ↗ by how much text and how many tools each language has:

  • Classes 0 and 1: languages with little text and few tools, such as Nigerian Pidgin, Hawaiian and Telugu, where code models struggle most.
  • Classes 2 and 3: languages with more resources, such as Amharic and Georgian.

The solution must be written in the programming language of the signature. The correct program does not change with the natural language. The test problems are held out until the test phase.

def sum_even(nums: list[int]) -> int:
    """
    Return the sum of all even numbers in the list.

    Example: sum_even([1, 2, 3, 4]) == 6
    """
    return sum(n for n in nums if n % 2 == 0)
/**
 * Return the sum of all even numbers in the list.
 *
 * Example: sum_even([1, 2, 3, 4]) returns 6
 */
long long sum_even(const long long *nums, int nums_len) {
    long long s = 0;
    for (int i = 0; i < nums_len; i++)
        if (nums[i] % 2 == 0) s += nums[i];
    return s;
}
-- Return the sum of all even numbers in the list.
--
-- Example: sum_even({1, 2, 3, 4}) == 6
function sum_even(nums)
  local s = 0
  for _, n in ipairs(nums) do
    if n % 2 == 0 then s = s + n end
  end
  return s
end
