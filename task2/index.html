The task

Catch a malicious coding prompt in any language or script

Input

One prompt to a code model, code-mixed across low-resource languages or transliterated into a non-Latin script.

→
Output

Benign or adversarial (Subtask A), and the attack type for adversarial prompts (Subtask B).

Background

Code-model safety filters are calibrated almost entirely on English. Rewrite a malicious request in a low-resource language, or spell it out in another script, keep the code keywords intact, and many filters stop working. In MALICE, the best classifier's accuracy fell from 0.93 on English to 0.21 on code-mixed malicious prompts, and even the most safety-aligned model tested produced about 3× more malicious code.

Findings from MALICE ↗ (Raihan, Meher, Dhingra, Zampieri; Findings of EMNLP 2026).

Two subtasks

A

Benign or adversarial?

Binary classification of each prompt sent to a code model. This is the main leaderboard.

Label: 0 benign, 1 adversarial

B

Which attack?

For adversarial prompts, identify the attack type. Finer-grained, and closer to what a real guardrail needs to log.

Attack categories are listed with the training data

Every prompt is either code-mixed or transliterated, across 18 task languages.
