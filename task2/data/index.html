What you get

Each example is one prompt with a Subtask A label (benign or adversarial) and, for adversarial prompts, a Subtask B attack type. The task builds on MALICE, a benchmark of about 250K code-mixed and transliterated adversarial prompts, split evenly between the two attack styles.

How the prompts are built

A malicious English coding request from an established security benchmark is translated sentence by sentence into low-resource languages, or transliterated into a non-Latin script. Programming keywords stay as they are.
