##About the Workshop

Research at the intersection of natural language and code is among the most active areas in NLP, yet the ACL community has no dedicated workshop on the topic.

Code models, exemplified by CodeLLMs, are now a standing track at ACL conferences, but the benefits remain concentrated in a very narrow slice of the world's languages: models are prompted overwhelmingly in English, evaluated almost exclusively on Python and a handful of high-resource programming languages, and equipped with safety mechanisms that are rarely tested beyond English inputs.

LangCode 2027 is a forum for research that makes code generation work for everyone — speakers of all natural languages, users of all programming languages, and deployments that must remain safe under adversarial pressure, offer desired explainability and interpretability, and align with human values and practices. We treat linguistic variation and safety as intertwined: guardrails calibrated on English degrade sharply on other languages, so a code model cannot be safe for all users unless it is robust for all languages.

The three axes of robustness

AXIS I

Across natural languages

Code generation, explanation, and documentation from prompts written in any language, not only English.

AXIS II

Across programming languages

Low-resource, emerging, legacy, and domain-specific programming languages that current models handle poorly.

AXIS III

Against adversaries

Secure generation, guardrails, and defenses against jailbreaks and prompt injection — in every language.

Alongside these three axes, the workshop welcomes submissions on the explainability and interpretability of CodeLLMs and on human–CodeLLM (and CodeLLM agent) alignment.

##Topics of Interest

Mirroring the pillars in the workshop title, plus a fifth area for applications, we invite submissions including but not limited to:

01Secure Code Generation

  • Secure code generation, including vulnerability-aware training and decoding
  • Guardrails for code models: input filtering, output auditing, and policy enforcement
  • Adversarial attacks on CodeLLMs: jailbreaks, prompt injection, and obfuscation
  • Safety of agentic coding systems

02Trustworthiness in Code LLMs

  • Explainability and interpretability of code models and their failure modes
  • Calibration, uncertainty, and hallucination in code generation
  • Contamination-aware benchmarks and evaluation
  • Alignment of code models and agents with human intents and practices

03Robustness in Code Models

  • Robustness to paraphrasing, dialectal variation, and code-mixed prompts
  • Support for low-resource, emerging, legacy, and domain-specific programming languages
  • Adaptation to new programming languages and distribution shift

04Multilingual Code Generation

  • Code generation, explanation, and documentation from non-English prompts
  • Cross-lingual transfer and adaptation to new natural languages
  • Data curation and synthetic data for underrepresented languages

05Code LLM Applications

  • Efficient code models for low-compute settings and equitable access
  • Case studies on deploying code models across languages and communities
  • CodeLLMs in computing education, including feedback for non-English-speaking learners

##Shared Tasks

LangCode 2027 will host two shared tasks on CodaBench, with sandboxed evaluation harnesses, public baselines, and starter kits. Participation is free, and constrained tracks keep low-compute teams competitive.

Task 1 / Multilingual Code Generation

100+ natural languages execution-based Pass@1 macro-averaged across tiers held-out problems

Participants generate Python solutions to programming problems presented in more than 100 natural languages spanning high-, mid-, and low-resource tiers. Building on mHumanEval, the task uses newly authored held-out problems to limit contamination. Systems are ranked by execution-based Pass@1 on hidden tests, macro-averaged across language tiers so that high-resource performance alone cannot win; per-language performance and the high–low-resource gap are also reported.

CodaBench page: coming soon

Task 2 / Adversarial Prompt Detection for Code Models

18 languages ~250K prompts macro-F1 surprise-language leaderboard

Systems classify CodeLLM prompts as benign or adversarial, with a subtrack for attack-type classification. The task builds on MALICE (Findings of EMNLP 2026), a roughly 250K-prompt benchmark spanning 18 languages together with code-mixed and transliterated adversarial variants. Since MALICE reveals substantial cross-lingual degradation in existing guardrails, the task targets a documented security gap. Evaluation uses macro-F1, including a cross-lingual leaderboard on surprise languages.

##Format & Participation

Format
One day, in person, hybrid. Authors who cannot travel can present remotely; if needed, the full program can run virtually.
Reviewing
OpenReview, with an option to commit pre-reviewed ARR papers.
Expected scale
50–60 submissions and 60–80 attendees, based on participation in related code models research and the organizers' shared task record.
Venue preference
  1. NAACL
  2. EACL
  3. ACL
  4. EMNLP
  5. COLING
Track record. BLP-2025 — a code generation shared task led by our organizers — drew 152 participants, 63 teams, and 488 submissions. The organizers have also run successful shared tasks at VarDial and WMT.

Diversity and Inclusion

LangCode contributes to academic diversity by design. Beyond academic diversity, we seek broad geographic, institutional, demographic, and career-stage representation among invited speakers and the program committee. We disseminate the call for papers through multilingual NLP, low-resource language, software engineering, security, and relevant affinity communities.
