##About the Workshop

Research at the intersection of language and code has become one of the most active areas in NLP, yet the benefits of code language models remain concentrated in a narrow slice of the world's languages: models are prompted overwhelmingly in English, evaluated almost exclusively on a handful of high-resource programming languages, and equipped with safety mechanisms that are rarely tested beyond English inputs.

LangCode 2027 is a forum for research that makes code generation work for everyone — speakers of all natural languages, users of all programming languages, and deployments that must remain safe under adversarial pressure, offer explainability and interpretability, and align with human values and practices. We treat linguistic variation and safety as inseparable: guardrails calibrated on English degrade sharply on other languages, so a code model cannot be safe for all users unless it is robust for all languages.

LangCode 2027 has been proposed to the joint EACL/COLING/NAACL/ACL/EMNLP 2027 workshop call, with NAACL 2027 (San Francisco) as the preferred venue. This page will be updated when the outcome is announced on October 2, 2026.

##Topics of Interest

Mirroring the pillars in the workshop title, plus a fifth area for applications, we invite submissions including but not limited to:

01Security

  • Secure code generation, including vulnerability-aware training and decoding
  • Guardrails for code models: input filtering, output auditing, policy enforcement
  • Adversarial attacks on CodeLLMs: jailbreaks, prompt injection, obfuscation
  • Detection and repair of vulnerable or malicious generated code
  • Safety of agentic coding systems

02Trustworthiness

  • Explainability and interpretability of code models and their failure modes
  • Alignment of code models and agents with human intents and practices
  • Calibration, uncertainty, and hallucination in code generation
  • Contamination-aware benchmarks and evaluation

03Robustness

  • Robustness to paraphrasing, dialectal variation, and code-mixed prompts
  • Support for low-resource, emerging, legacy, and domain-specific programming languages
  • Adaptation to new programming languages and distribution shift

04Multilinguality

  • Code generation, explanation, and documentation from non-English prompts
  • Cross-lingual transfer and adaptation to new natural languages
  • Data curation and synthetic data for underrepresented languages

05Applications

  • CodeLLMs in computing education, including feedback for non-English-speaking learners
  • Efficient code models for low-compute settings and equitable access
  • Case studies on deploying code models across languages and communities

Reviewing will run on OpenReview, with an option to commit pre-reviewed ARR papers. The full call for papers, including formatting and archival options, will be published with the first CFP.

##Shared Tasks

LangCode 2027 will feature two shared tasks, hosted on CodaBench with sandboxed evaluation harnesses, public baselines, and starter kits. Participation is free, and constrained tracks keep low-compute teams competitive.

Task 1 / Multilingual Code Generation

100+ natural languages · execution-based Pass@1 · tier-macro-averaged

Participants receive programming problems with prompts in over 100 natural languages spanning high-, mid-, and low-resource tiers, and must generate correct Python solutions. The task builds on the mHumanEval methodology, refreshed with newly authored held-out problems to prevent contamination. Systems are ranked by execution-based Pass@1 on hidden unit tests, macro-averaged across language tiers so that high-resource performance alone cannot win; per-language scores and the high–low-resource gap are also reported.

CodaBench page: coming soon

Task 2 / Adversarial Prompt Detection for Code Models

18 languages · macro-F1 · surprise-language leaderboard

Systems classify prompts directed at a CodeLLM as benign or adversarial (eliciting malicious code, jailbreaks, prompt injection, or obfuscated harmful requests); a second subtrack classifies the attack technique. The data derive from the organizers' MALICE benchmark (Findings of EMNLP 2026): adversarial prompts across 18 natural languages built from nine malicious-code benchmarks via code-mixing and transliteration, rebalanced with fresh benign prompts. Evaluation uses macro-F1, with a cross-lingual leaderboard on surprise languages unseen in training.
