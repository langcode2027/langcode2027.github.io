{{i:globe}}How the prompts are built

The task builds on MALICE, a benchmark of about 250K code-mixed and transliterated adversarial prompts, split evenly between the two attack styles. A malicious English coding request from an established security benchmark is translated sentence by sentence into low-resource languages, or transliterated into a non-Latin script. Programming keywords stay as they are.

  • ~250Kadversarial prompts in MALICE
  • 18task languages
  • 9source security benchmarks
