{{i:gauge}}How the score works

Score=1|T|∑t∈TPass@1(t)

{{i:check}}Pass@1(t)

The share of problems in tier t whose single generated solution passes all hidden tests. Execution-based, no partial credit.

{{i:scale}}Every tier counts

Pass@1 is macro-averaged across the language resource tiers T, each with the same weight, so high-resource languages alone cannot win.
