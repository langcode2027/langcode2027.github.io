Given a programming problem described in one of more than 100 natural languages, write a solution in the requested programming language, such as Python, C, C++, or Java, that passes hidden unit tests. Your system should solve the problem no matter which natural language it is posed in.

The task

{{i:target}}Write the same program, whatever language the problem is in

{{i:inbox}}Input

A function signature in one programming language (Python, C, C++, Java, and others) and a problem description in one of 100+ natural languages.

→
{{i:tag}}Output

One solution in the same programming language. It counts only if it passes every hidden unit test.

{{i:book}}Background

Code models are prompted mostly in English and benchmarked mostly on English. Many programmers describe what they want in another language, and a model that solves a problem in English can fail on the same problem written in a lower-resource language. This task measures that gap and rewards systems that close it.

{{i:gauge}}How systems are scored

Pass@1

{{i:check}}One attempt

The share of problems whose single generated solution passes all hidden tests.

Execution-based, no partial credit

avg

{{i:scale}}Every tier counts

Pass@1 is macro-averaged across language resource tiers, so high-resource languages alone cannot win.

Each resource tier carries the same weight

tests

{{i:eye-off}}Hidden tests

Test cases are never released. The test problems are newly written and held out.

Limits contamination from pretraining data

Full metric and the two tracks (constrained and open): see Leaderboard.
