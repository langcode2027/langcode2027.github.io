shared_task[1]Multilingual Code Generation

One problem, 50 natural languages, one correct program

Given a programming problem described in one of 50 natural languages, among them Amharic, Georgian, Hawaiian, Nigerian Pidgin and Telugu, write a solution in the requested programming language, such as Python, C or Lua, that passes the hidden test cases. Your system should solve the problem no matter which natural language it is posed in.

The task

{{i:target}}Write the same program, whatever language the problem is in

{{i:inbox}}Input

A function signature in one programming language (Python, C, Lua and others) and a problem description in one of 50 natural languages.

→
{{i:tag}}Output

One solution in the same programming language. It counts only if it passes every test case.

{{i:book}}Background

Code models are prompted mostly in English and benchmarked mostly on English. Many programmers describe what they want in another language, and a model that solves a problem in English can fail on the same problem written in a lower-resource language. This task measures that gap and rewards systems that close it.
